# Безопасность

## HTTPS

Всегда используйте HTTPS в продакшне.

## CORS

Настройте API сервер для разрешения домена вашей панели.

## Хранение сессий

Состояние авторизации хранится в `sessionStorage`, которое очищается при закрытии вкладки браузера. Это безопаснее, чем `localStorage` для хранения сессий.

## Переменные окружения

Переменные окружения инжектируются при запуске в Docker, а не зашиваются в JS-бандл. Подробности в [Переменные окружения](./environment.md).

## CSP

Настройте заголовки Content Security Policy для вашего развертывания.
