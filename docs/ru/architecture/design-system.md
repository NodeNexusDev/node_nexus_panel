# Дизайн-система

## Стилизация

TailwindCSS 4 для utility-first стилизации.

## Компоненты

Переиспользуемые компоненты в `src/components/`:

- Кнопки
- Формы
- Таблицы
- Модальные окна
- Карточки
- Навигация

## Тема

Конфигурация темы в `tailwind.config.ts`.

## Иконки

Используйте эмодзи или библиотеки иконок по необходимости.
