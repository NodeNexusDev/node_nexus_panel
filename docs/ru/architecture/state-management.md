# Управление состоянием

## Подход

Панель использует встроенные средства управления состоянием React:

- **Локальное состояние:** `useState` для состояния компонента
- **Общее состояние:** Context API для состояния между компонентами
- **Состояние сервера:** Пользовательские хуки с интеграцией API

## Паттерны

- Поднимайте состояние вверх при необходимости
- Предпочитайте композицию прокидыванию пропсов
- Используйте пользовательские хуки для переиспользуемой логики
