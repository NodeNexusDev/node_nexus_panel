# Docker

Управление Docker-ресурсами на подключённых нодах.

## Обзор

Страница Docker предоставляет единый интерфейс для управления контейнерами, образами, сетями и томами на всех подключённых к Docker нодах.

## Выбор ноды

Выберите Docker-ноду для управления из выпадающего списка вверху страницы. В списке отображаются только ноды с типом подключения Docker.

## Контейнеры

Просмотр и управление всеми контейнерами на выбранной ноде.

### Возможности

- **Обновления в реальном времени** через SSE — статус контейнеров обновляется автоматически
- **Поиск** по имени контейнера или образу
- **Фильтрация** по статусу (запущенные, остановленные, приостановленные)
- **Разворачиваемые строки** — нажмите на контейнер для просмотра деталей

### Действия с контейнерами

- **Запуск** / **Остановка** / **Перезапуск** — управление жизненным циклом
- **Удаление** — удаление контейнера (с подтверждением)
- **Просмотр** — просмотр полной конфигурации контейнера в формате JSON
- **Терминал** — открытие интерактивной терминальной сессии внутри контейнера

### Детали контейнера

Разверните строку контейнера для просмотра:

- **Просмотр** — полный вывод `docker inspect`
- **Логи** — логи stdout/stderr контейнера
- **Терминал** — интерактивный терминал с историей команд

## Образы

Просмотр и управление Docker-образами на выбранной ноде.

### Возможности

- **Загрузка образов** — введите имя образа и необязательный тайм-аут
- **Удаление образов** — удаление неиспользуемых образов
- **Информация об образе** — размер, дата создания, теги

## Сети

Просмотр и управление Docker-сетями.

### Возможности

- **Список сетей** — драйвер, область, подключённые контейнеры
- **Удаление сетей** — удаление неиспользуемых сетей (с подтверждением)

## Тома

Просмотр и управление Docker-томами.

### Возможности

- **Список томов** — имя, драйвер, точка монтирования, время создания
- **Удаление томов** — удаление неиспользуемых томов (с подтверждением)

## Docker-подключение

Для использования управления Docker ноды должны быть настроены с:

- **Тип подключения:** Docker
- **Docker Host:** путь к Docker-сокету (например, `/var/run/docker.sock`)

Инструкции по добавлению Docker-подключённых нод см. в разделе [Ноды](nodes.md).
