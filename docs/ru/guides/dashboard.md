# Панель управления

Панель управления предоставляет обзор ваших нод и состояния системы.

## Возможности

### Карточки статистик

Пять карточек статистик с индикаторами трендов:

| Карточка | Описание |
|----------|----------|
| Всего нод | Общее количество зарегистрированных нод |
| Онлайн | Активные на данный момент ноды |
| Оффлайн | Недоступные ноды |
| Всего команд | Общее количество выполненных команд |
| Docker-контейнеры | Запущенные и остановленные контейнеры |

### Избранное

Быстрый доступ к избранным нодам, командам и скриптам. Переключайте избранное с помощью кнопки-звёздочки на любой сущности.

### Метрики

Интерактивные графики метрик выполнения команд и скриптов:

- **Типы графиков:** Столбчатые и облачные графики через компонент `MetricsChart`
- **Пресеты дат:** 7д, 30д, 90д, Все
- **Группировка:** День, Неделя, Месяц
- **Индикаторы трендов:** Процентное изменение по сравнению с предыдущим периодом

### Быстрые действия

Четыре карточки быстрых действий:

- **Выполнить команду** — переход на страницу команд
- **Добавить ноду** — переход на страницу нод
- **Запустить скрипт** — переход на страницу скриптов
- **Просмотреть логи** — переход к журналу аудита

### Последние ноды

Список недавно просмотренных нод с бейджами статуса.

### Последняя активность

Лента последних действий по всей системе (выполнение команд, запуск скриптов, изменение статуса нод).

## Визуальные эффекты

- Анимированный фон с частицами
- Паттерн dot grid overlay
- Градиентные орбы (indigo/purple) с анимацией float
- Glassmorphism на сайдбаре и хедере

## Макет

Дашборд рендерится внутри `MainLayout`, который предоставляет:
- **Сайдбар** (слева): Логотип и ссылки навигации
- **Хедер** (сверху): Переключатель языка (RU/EN), переключатель темы, индикатор SSE-соединения, триггер Command Palette (Ctrl+K), аватар пользователя с именем/email и кнопка выхода
