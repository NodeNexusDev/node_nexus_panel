# Панель управления

Главная страница с обзором нод и метрик системы.

## Возможности

- Карточки статистик (Всего нод, Онлайн, Оффлайн, Команд сегодня)
- Мини-чарты спарклайнов с активностью за 7 дней
- Список последних нод с бейджами статуса
- Сетка быстрых действий (Выполнить команду, Добавить ноду, Запустить скрипт, Логи)
- Skeleton shimmer-загрузка
- Каскадные анимации появления

## Визуальные эффекты

- Анимированный фон с частицами
- Паттерн dot grid overlay
- Градиентные орбы (indigo/purple) с анимацией float
- Glassmorphism на сайдбаре и хедере

## Макет

Дашборд рендерится внутри `MainLayout`, который предоставляет:
- **Сайдбар** (слева): Логотип и ссылки навигации
- **Хедер** (сверху): Переключатель языка (RU/EN), переключатель темы, индикатор WebSocket, триггер Command Palette (Ctrl+K), аватар пользователя с именем/email и кнопка выхода
