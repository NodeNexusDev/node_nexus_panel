# FAQ

Часто задаваемые вопросы.

## Общие

**Какие браузеры поддерживаются?**

Chrome, Firefox, Safari, Edge (последние 2 версии).

**Можно ли использовать панель с несколькими экземплярами API?**

Настройте каждый экземпляр отдельным развертыванием.
