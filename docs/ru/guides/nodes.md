# Ноды

Управление и мониторинг подключённых нод.

## Список нод

Просмотр всех нод со статусом, тегами и системной информацией:

- **Поиск** по имени или хосту (debounce 300мс)
- **Фильтрация** по статусу (активна, недоступна, ошибка)
- **Фильтрация** по тегам (один тег — сервер, несколько — `Фильтр по нескольким тегам показывает только загруженные страницы`)
- **Сортировка** по имени, хосту, статусу, тегам, Docker, дате
- **Избранное** — отмечайте ноды ★
- **Колонка Docker** — бейдж `docker` если `has_docker`
- **Массовая панель** — выделите чекбоксом, `{{count}} выбрано` (`one/few/many`), действия: `Проверка`, `Метрики`, `Обновить`, `Проверить` (учётные данные), `Удалить`, `Выполнить команды`, `Скрипты` (без префикса `Bulk`)
- **Без per-row кнопок** — клик по строке открывает Drawer (как в командах/скриптах)

## Добавление нод

1. Нажмите «Добавить ноду»
2. Заполните форму:
   - **Имя** — отображаемое имя
   - **Хост** — IP или хост
   - **Порт** — SSH-порт (по умолчанию 22)
   - **Тип подключения** — SSH
   - **Имя пользователя** — SSH-пользователь
   - **Пароль** — SSH-пароль (оставьте пустым при ключе)
   - **SSH-ключ** — приватный ключ (оставьте пустым при пароле)
   - **Парольная фраза** — пароль для ключа
   - **Docker-хост** — путь к сокету
   - **Есть Docker** — переключатель
   - **Теги** — через запятую, `^[a-z0-9_-]{1,30}$`, до 20, дубликаты и регистр нормализуются
3. Нажмите «Проверить» для теста подключения

## Drawer ноды (Variant C)

Клик по строке → боковая панель `800px` (`lg` `max-w-4xl w-[min(800px,92vw)]`), `slide-in-right 0.2s`, `backdrop-blur`, портал в `body`, `Esc`/`Tab` trap, `body overflow hidden`.

7 вкладок:

### Обзор

Имя, `host:port` (копировать), описание, тип подключения, статус, пользователь (копировать), Docker-хост, Docker, теги, создано/обновлено. Бейджи статуса.

### Метрики

Реальное время `GET /nodes/{id}/metrics` (10s stale): CPU (ядер + %), память (исп/всего %), диск, `Время работы с`, `Средняя нагрузка` 1m/5m/15m. `Card` + `KeyValueList`.

### Статистика

`GET /commands/stats?node_id` с `date_from/date_to`, `StatsGrid` всего/процент успеха/ср. время/неудачно.

### История

Две infinite ленты (limit 5, `InfiniteScroll`): история статусов (`active→unreachable` + source) и история команд (`command_fingerprint` mono, `exit_code` бейдж, `Повторить` для `failed`). Имя резолвится через `Command` где доступно.

### Редактирование

Инлайн форма: имя, хост, порт, тип, описание (1000), учётные данные (пароль/SSH-ключ/фраза с `Очистить`), Docker (хост + флаг), теги. `Сохранить` → `PATCH /nodes/{id}`.

### Выполнение (Команды)

Вложенные `Команда/Своя`. `Команда` → поиск чекбокс-список команд (массовый выбор, `выбрано` + `по умолчанию` подсказка), `Своя` → `команда` + `таймаут`. `Выполнить` → `POST /commands/executions` `M×N` `command_ids+node_ids` с `207`, per-service `BulkResult`, история кастомных выводов с `Очистить`.

### Скрипты

Аналогично: поиск скриптов, `Запустить` → `POST /scripts/executions` `M×N`, per-service шаги `ExecutionResult`.

## Действия с нодой (в Drawer)

- **Проверить** — `POST /nodes/checks`
- **Проверить** (учётные данные) — бейдж `Подключение установлено/Не удалось`
- **Редактировать** — вкладка Редактирование
- **Удалить** — футер `Удалить` → `DELETE /nodes/{id}`
- **Docker** — `Открыть Docker` → `/docker?node=:id`
