# Ноды

Управление и мониторинг подключённых нод.

## Список нод

Просмотр всех зарегистрированных нод со статусом, временем последнего подключения и системной информацией.

## Добавление нод

1. Установите агент NodeNexus на целевую машину
2. Настройте endpoint API
3. Зарегистрируйте ноду через панель

## Действия с нодами

- Перезапуск
- Выполнение команд
- Просмотр логов
- Изменение конфигурации
