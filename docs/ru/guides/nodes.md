# Ноды

Управление и мониторинг подключённых нод.

## Список нод

Просмотр всех зарегистрированных нод со статусом, тегами и системной информацией. Возможности:

- **Поиск** по имени или хосту
- **Фильтрация** по статусу (активные, недоступные, оффлайн)
- **Фильтрация** по тегам
- **Массовые операции** — выделите несколько нод для массового удаления, массовой проверки или массового управления тегами
- **Избранное** — добавляйте ноды в избранное для быстрого доступа

## Добавление нод

1. Нажмите кнопку «Добавить ноду»
2. Заполните форму:
   - **Имя** — отображаемое имя
   - **Хост** — IP-адрес или имя хоста
   - **Порт** — SSH-порт (по умолчанию: 22)
   - **Тип подключения** — SSH, Docker или Proxmox
   - **Имя пользователя** — SSH-пользователь
   - **Пароль** — SSH-пароль (необязателен при использовании ключа)
   - **SSH-ключ** — содержимое приватного ключа (необязательно)
   - **Пассфраза** — пассфраза SSH-ключа (необязательно)
   - **Docker Host** — путь к Docker-сокету (для Docker-подключений)
   - **Теги** — теги через запятую
3. Нажмите «Проверить» для тестирования подключения перед сохранением

## Вкладки детальной информации ноды

Каждая нода имеет 6 вкладок:

### Обзор

Основная информация о ноде: имя, хост, тип подключения, статус, теги и быстрые действия (редактирование, удаление, проверка).

### Метрики

Метрики системы в реальном времени:

- **CPU** — процент использования и количество ядер
- **Память** — всего, использовано и процент
- **Диск** — всего, использовано и процент
- **Аптайм** — с какого времени нода работает

### Статистика

Статистика выполнения с графиками, показывающими количество выполненных команд и скриптов во времени.

### История статуса

Хронология изменений статуса (активная → недоступная → активная) с временными метками и источниками.

### История команд

Список команд, выполненных на этой ноде:

- Текст команды
- Код возврата
- Время выполнения
- Вывод stdout/stderr
- Повторная попытка для неудачных команд

### Теги

Управление тегами ноды:

- Добавление тегов через поле ввода
- Удаление тегов в один клик
- Теги используются для фильтрации и массовых операций

## Действия с нодами

- **Проверка** — запуск проверки состояния
- **Редактирование** — изменение конфигурации ноды
- **Удаление** — удаление ноды
- **Выполнение** — запуск произвольной команды
