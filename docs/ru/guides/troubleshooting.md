# Решение проблем

Частые проблемы и их решения.

## Проблемы с подключением

**Панель не может подключиться к API**

- Проверьте правильность `VITE_API_URL`
- Проверьте, что API сервер запущен
- Проверьте конфигурацию CORS

## Проблемы авторизации

**Вход не удаётся**

- Проверьте учётные данные
- Проверьте срок действия токена
- Очистите localStorage и попробуйте снова

## Проблемы с нодами

**Нода показывает офлайн**

- Проверьте, что агент ноды запущен
- Проверьте сетевую связность
- Проверьте правила файрвола
