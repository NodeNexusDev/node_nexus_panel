# Команды

Выполнение команд на удалённых нодах.

## Список команд

Просмотр шаблонов команд с `Поиск` по имени/команде, `Фильтр` по `тегам` (один сервер, `несколько` — подсказка), `Сортировка` по имени/команде/тегам, `Infinite` 20. Без per-row кнопок — клик → `CommandDrawer` Variant C `800px`. Массовая панель для выбранных: `Выполнить (кол-во)` → `BulkRunCommandsModal` `command_ids+node_ids` `M×N`, `Клонировать`, `Удалить` с `207`.

## Создание команд

Модалка `Создать команду`: `название`, `команда` (`df -h`), `описание`, `теги` (`^[a-z0-9_-]{1,30}$` до 20), `параметры` (`имя/тип/обязательный/по умолчанию` via `ParameterEditor`). `POST /commands/` `BulkResult`.

## Drawer команды (Variant C)

Клик → боковая панель `800px` `slide-in-right 0.2s` портал:

5 вкладок: `обзор` (команда `pre` + копировать, описание, создано/обновлено), `параметры` (список `имя тип` бейджи `обязательно`), `статистика` (`GET /commands/{id}/stats` с `date_from/date_to` + `StatsGrid`), `выполнить` (поиск чекбокс нод `выбрано` + `params` → `POST /commands/executions` `M×N` `207`), `редактировать` (`react-hook-form` `commandUpdateSchema`).

Шапка: `Клонировать`, `Удалить`. Без `Просмотр` — детальные роуты удалены.
