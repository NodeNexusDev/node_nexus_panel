# Каталог ошибок

## Частые ошибки

| Ошибка | Причина | Решение |
|--------|---------|---------|
| `NETWORK_ERROR` | API недоступен | Проверьте URL API и статус сервера |
| `AUTH_EXPIRED` | Токен истёк | Повторите вход |
| `FORBIDDEN` | Недостаточно прав | Проверьте роль пользователя |
| `NOT_FOUND` | Ресурс не найден | Проверьте существование ресурса |
