# Глоссарий

## Термины

**Нода** — Машина (сервер), на которой запущен агент NodeNexus. Не путайте с сервером API.

**Панель** — Веб-приложение для управления нодами.

**API** — Сервер API NodeNexus.

**Контейнер** — Изолированное окружение Docker, запущенное на ноде.

**Образ** — Шаблон для создания контейнера (Docker image).

**Том** — Постоянное хранилище данных Docker (volume).

**Сеть** — Виртуальная сеть Docker для связи контейнеров.

**Тег** — Пользовательская метка для нод/команд/скриптов. Не путайте с метками Docker (labels).

**Метка** — Ключ-значение Docker (labels) для контейнеров/образов.

**Prune** — Удаление неиспользуемых Docker-ресурсов (очистка).

**WebSocket** — Протокол для двусторонней коммуникации в реальном времени.

**JWT** — JSON Web Token для аутентификации.

**Команда** — Исполняемая инструкция, отправленная на ноду.

**Скрипт** — Переиспользуемая команда или набор команд.
