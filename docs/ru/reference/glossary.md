# Глоссарий

## Термины

**Нода** — Машина, на которой запущен агент NodeNexus.

**Панель** — Это веб-приложение для управления нодами.

**API** — Backend API сервер NodeNexus.

**WebSocket** — Протокол для двусторонней коммуникации в реальном времени.

**JWT** — JSON Web Token для аутентификации.

**Команда** — Исполняемая инструкция, отправленная на ноду.

**Скрипт** — Переиспользуемая команда или набор команд.
