# Авторизация

NodeNexus Panel авторизуется через NodeNexus API.

## Вход

1. Введите учётные данные на странице входа
2. Панель получит JWT токен от API
3. Токен сохраняется в localStorage для сессии

## API ключи

Для программного доступа генерируйте API ключи в настройках панели.
