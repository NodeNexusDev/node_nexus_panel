# Установка

## Требования

- Node.js 22+
- npm 10+

## Быстрый старт

```bash
git clone https://github.com/NodeNexusDev/node_nexus_panel.git
cd node_nexus_panel
npm install
npm run dev
```

## Продакшн сборка

```bash
npm run build
npm run preview
```

Собранные файлы будут в директории `dist/`.
