# Компоненты

## Структура

```
src/
  components/    # Переиспользуемые UI компоненты
  pages/         # Компоненты маршрутов
  hooks/         # Пользовательские React хуки
  utils/         # Утилиты
  api/           # API клиент
  assets/        # Статические файлы
```

## Конвенции

- Используйте TypeScript для всех компонентов
- Предпочитайте функциональные компоненты с хуками
- Держите компоненты маленькими и сфокусированными
- Размещайте стили рядом с компонентами используя Tailwind
