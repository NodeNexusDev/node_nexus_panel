# Тестирование

## Настройка

Настройка фреймворка тестирования (когда будет добавлена).

## Запуск тестов

```bash

```

## Написание тестов

Размещайте тестовые файлы рядом с компонентами:

```
src/
  components/
    Button.tsx
    Button.test.tsx
```
