# Installation

## Prerequisites

- Node.js 22+
- npm 10+

## Quick Start

```bash
git clone https://github.com/NodeNexusDev/node_nexus_panel.git
cd node_nexus_panel
npm install
npm run dev
```

## Production Build

```bash
npm run build
npm run preview
```

The built files will be in the `dist/` directory.
