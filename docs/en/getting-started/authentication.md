# Authentication

NodeNexus Panel authenticates against the NodeNexus API.

## Login

1. Enter your credentials on the login page
2. The panel will obtain a JWT token from the API
3. Token is stored in local storage for session persistence

## API Keys

For programmatic access, generate API keys in the panel settings.
