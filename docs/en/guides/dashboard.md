# Dashboard

The dashboard provides an overview of your nodes and system health.

## Features

- Stat cards with values (Total Nodes, Online, Offline, Commands Today)
- MiniChart sparklines showing 7-day activity per stat
- Recent nodes list with status badges
- Quick actions grid (Execute Command, Add Node, Run Script, View Logs)
- Skeleton shimmer loading states
- Staggered entrance animations

## Visual Effects

- Animated particle background with floating dots
- Dot grid overlay pattern
- Gradient orbs (indigo/purple) with float animation
- Glassmorphism on sidebar and header
