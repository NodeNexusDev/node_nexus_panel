# Nodes

Manage and monitor your connected nodes.

## Node List

View all registered nodes with their status, last seen time, and system info.

## Adding Nodes

1. Install the NodeNexus agent on the target machine
2. Configure the API endpoint
3. Register the node through the panel

## Node Actions

- Restart
- Execute commands
- View logs
- Update configuration
